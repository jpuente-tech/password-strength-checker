Password Strength Checker 🔐

Project Overview

This is my first Python cybersecurity project, created as part of my journey toward a career in cybersecurity.

The program evaluates whether a user-entered test password meets a set of basic password requirements.

Features

- Checks password length (minimum 12 characters)
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Reports whether all requirements are met

Technologies Used

- Python 3
- Visual Studio 2022
- GitHub

How to Run

1. Download `password_checker.py`.
2. Open it in a Python-compatible development environment.
3. Run the program.
4. Enter a made-up test password.
5. Review the results displayed in the console.

Testing

I tested the program using different inputs, including:

- Passwords that meet all requirements
- Passwords missing uppercase letters
- Passwords missing lowercase letters
- Passwords without special characters
- Empty input

These tests helped me understand how the program responds to different conditions.

Future Improvements

As I continue developing my Python skills, I plan to improve this project by adding more detailed feedback, additional test cases, and better password-handling practices.

Security Note

This is an educational password requirements checker, not a comprehensive password strength assessment. Meeting these requirements does not guarantee that a password is secure. Use fictional passwords when testing the program.
